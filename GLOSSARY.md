# RuTube Client

Безаккаунтный клиент RuTube для Android и Android TV: воспроизведение без рекламы, вся библиотека пользователя хранится локально на устройстве.

## Контент

**Video**:
Единица контента RuTube; минимальная воспроизводимая вещь. Имеет автора (Channel) и может принадлежать сериалу (TvShow).
_Avoid_: ролик, клип, запись

**TvShow**:
Сериал из каталога RuTube: метаинформация, сезоны, эпизоды.
_Avoid_: шоу, show, сериал (в коде и документации — TvShow)

**Episode**:
Video, принадлежащее сезону TvShow. Порядок просмотра определяется номером сезона и серии, а не датой публикации.
_Avoid_: эпизод (в коде — Episode, в UI-текстах — «серия»)

**Series heuristics**:
Распознавание серий по заголовкам видео («S02E03», «1 сезон 2 серия», «5 выпуск») и правила их фильтрации/сортировки — core:model/Series.kt. Единственный источник истины для «какие видео — серии одного сериала и в каком порядке»; используется экранами и Series discovery.

**Channel**:
Автор видео на RuTube; страница со списком его видео.
_Avoid_: автор, канал-пользователь

**Catalog**:
Курируемые подборки RuTube (фильмы, сериалы, мультфильмы, аниме) плюс список категорий.

## Воспроизведение

**Playback session**:
Воспроизведение одного видео за один заход на экран видео: подключение стрима, resume, повтор при истёкшей подписи, сохранение позиции, таймеры. Принадлежит экрану видео; смена серии — это новая сессия (см. docs/adr/0001).

**Stream URL**:
Подписанный HLS-URL, который RuTube выдаёт на короткое время. Инвариант: переполучается непосредственно перед воспроизведением и повторно при ответе CDN 403.
_Avoid_: прямая ссылка, ссылка на видео

**Playback position**:
Позиция последнего просмотра видео, сохранённая локально для resume и индикаторов прогресса.

**Continue watching**:
Ряд на главной экране из локальной истории: видео с ненулевой сохранённой позицией.

**Autoplay next**:
Отсчёт после окончания серии, по истечении которого автоматически открывается следующая серия.

**Still watching**:
Запрос «Вы всё ещё смотрите?» после длительного непрерывного воспроизведения.

## Локальная библиотека

**Library**:
Всё локальное состояние пользователя: история, закладки, подписки, оценки, загрузки, история поиска. Аккаунта нет by design.

**Bookmark**:
Видео, сохранённое «в избранное» локально.
_Avoid_: избранное (в UI), favourite

**Subscription**:
Локальная подписка на Channel без аккаунта RuTube; лента подписок собирается из видео каналов.

**Rating**:
Локальная оценка видео (нравится / не нравится); на сервер RuTube не отправляется.

**Download**:
Video, скачанное в offline-кэш для воспроизведения без сети.
